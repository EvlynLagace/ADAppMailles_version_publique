# La couverture
La grille qui s'affiche représente votre couverture.

ADAppMailles l'a construite à partir de vos paramètres, avec les carrés les plus grands possible en évitant qu'un motif se répète sur deux tuiles adjacentes.

Le nom du motif à tricoter est inscrit dans chacune des tuiles, et la liste de ceux qui peuvent s'ajuster à la taille souhaitée est affichée.

Vous pouvez modifier les motifs utilisés en cliquant droit sur l'un des carrés. Notez que même l'un des motifs voisins peut être choisi, vous permettant plus de flexibilité pour personnaliser votre ouvrage.

En cliquant normalement (clic gauche), les instructions pour tricoter la tuile s'afficheront.

Finalement, il est possible de générer une autre couverture.
