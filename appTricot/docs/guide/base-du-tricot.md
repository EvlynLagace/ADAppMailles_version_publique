# Qu'est-ce qu'un tricot : la base de la base

Un tricot, c'est une suite de rangs.  Les rangs « endroit » sont le « bon » côté de l'ouvrage, bien que certains motifs soient réversibles et aient donc la même apparence d'un côté comme de l'autre.

## Qu'est-ce qu'un rang ?

Un rang, c'est simplement une séquence de mailles.  Les deux types de mailles de base sont les mailles endroit et les mailles envers.  Il existe d'autres types de mailles, mais ce ne sont que des variations utilisant les mêmes techniques.

## Le sens des rangs

Le plus souvent, le premier rang est tricoté sur l'ENDROIT de l'ouvrage.  Après en avoir tricoté la dernière maille, on le retourne  pour tricoter le second : c'est donc maintenant l'ENVERS de l'ouvrage que nous voyons.

Ainsi, les rangs ENDROIT et ENVERS s'alternent tout le long du tricot.

## La première étape : monter les mailles

Avant de tricoter le premier rang, il faut avoir sur son aiguille le nombre de mailles qui le composent.  Il faut donc « tricoter » le « rang 0 ».
