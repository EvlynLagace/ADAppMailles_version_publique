# Idées

## Notation de tricot

K : maille endroit  
P : maille envers  
\* \* : répéter les mailles qui se trouvent entre les * jusquà la fin du rang ou autrement spécifié  
\[ ] : répéter les mailles entre crochets le nombre de fois mentionné

## Liste de motifs simples  
Motifs constitués uniquement de mailles à l'endroits et de mailles à l'envers tirés du livre Vogue Knitting The Ultimate Stitch Dictionary

### Point Jersey  
R1 : * K *  
R2 : * P *  

### Point Mousse  
R1 : * K *  
R2 : * K *

### Moss Stitch - page 16
(multiple de 4 mailles)  
R1 (endroit) : * K2, P2 *  
R2 : * P2, K2 *  
R3 : * P2, K2 *  
R4 : * K2, P2 *  

### Seed Blocks - page 16  
(multiple de 7 mailles plus 5)  
R1 (endroit) : * [K1, P1]deux fois, K3 *  
R2 : [ K1, P1 ]deux fois, K1, * P2, [ K1, P1]deux fois, K1 *  
R3 à R6 :  répéter les R1 et R2 deux fois  
R7 : * P *  
R8 : * K *  

### Seed Stitch - page 16  
(multiple de 2 mailles plus 1)   
R1 (endroit) : K1, * P1, K1 *    
R2 (envers) : K1, * P1, K1 *  

### Moss Diamonds - page 17

### Seeded Windowpane - page 19
(multiple de 12 mailles plus 1)  
R1 (endroit) : * K6, P1, K5 *, K1  
R2 : P1, * P4, K1, P1, K1, P5*  
R3 : * K4 [ P1, K3 ]deux fois * K1  
R4 : P1, * P2, K1, P5, K1, P3 *  
R5 : * K2, P1, K7, P1, K1 *  
R6 : P1, * K1, P9, K1, P1 *  
R7 : * P1, K11 * P1  
R8 : Répéter R6  
R9 : Répéter R5  
R10 : Répéter R4  
R11 : Répéter R3  
R12 : Répéter R2  

### Single Basketweave - page 43
(multiple de 8 mailles)  
R1 (endroit) : * K *  
R2 à R6 : * K4, P4 *  
R7 : * K *  
R8 à R12 : * P4, K4 *  

### TV Static - page 47
(multiple de 8 mailles)   
R1 (endroit) : * K1, P1, K1, P5 *  
R2 (et tous les rangs envers ) : K les mailles endroits et P les mailles envers  
R3 : * K1, P1, K5, P1 *  
R5 : * K1, P5, K1, P1 *
R7 : * K5, P1, K1, P1 *
R9 : * P4, [ K1, P1 ] deux fois *  
R11 : * K3, P1, K1, P1, K2 *  
R13 : * P2, K1, P1, K1, P3 *  
R15 : * [ K1, P1 ]deux foix, K4 *
R16 : K les mailles endroits et P les mailles envers  

### Chevron Rib - page 57
(multiple de 18 mailles plus 1)  
R1 (endroit) : P1, * [ K2, P2 ]deux fois, K1, [ P2, K2 ]deux fois, P1 *  
R2 : * K1, [ P2, K2 ]deux fois, P1, [ K2, P2 ]deux fois *, K1  
R3 et R4 : Répéter R1 et R2  
R5 : P1, * P1, K2, P2, K2, P3,  [ K2, P2 ]deux fois *  
R6 : * [ K2, P2 ]deux fois, K3, P2, K2, P2, K1 * K1  
R7 et R8 : Répéter R5 et R6  
R9 : K1 * [ P2, K2 ]deux fois, P1, [ K2, P2 ]deux fois, K1 *  
R10 : * P1, [ K2, P2 ]deux fois, K1, [ P2, K2 ]deux fois * P1  
R11 et R12 : Répétéer R9 et R10  
R13 :  K1 * K1, P2, K2, P2, K3, [ P2, K2 ]deux fois *  
R14 : * [ P2, K2 ]deux fois, P3, K2, P2, K2, P1 * P1  
R15 et R16 : Répéter R13 et R14
